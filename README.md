# NJFOP Lodge 106 Website — Free Static Version

This is the first working version of the NJFOP Lodge 106 website, designed around the structure and professional feel of the New Jersey State FOP site.

## Included
- Responsive homepage
- About
- Members
- News
- Events
- Resources
- Retirees
- Contact
- Mobile navigation
- Lodge 106 logo
- No paid hosting required

## Important
This version does NOT claim to provide secure member authentication or online payments. Those require a backend/service and are planned for Phase 2.

## Publish free with GitHub Pages
1. Create a free GitHub account.
2. Create a public repository.
3. Upload all files and the `assets` folder.
4. Open Settings → Pages.
5. Select deployment from the `main` branch.
6. GitHub will provide the live website address.

## Before launch
Replace placeholder officer, contact, event, and organization information with official Lodge 106-approved content.
